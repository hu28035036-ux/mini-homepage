# /harness — 하네스 실행

본 명령은 현재 Phase에 필요한 하네스 체크리스트를 실행한다.

## 절차

1. `docs/10_CURRENT_STATE.md`에서 현재 Phase를 확인한다.
2. `docs/05_HARNESS_PLAN.md` §2에서 해당 Phase의 필수 하네스 목록을 가져온다.
3. 각 하네스 문서(`docs/harness/*.md`)의 체크리스트를 순서대로 점검한다.
4. 실패 항목은 즉시 `docs/08_VALIDATION_LOG.md`의 현재 Phase 엔트리에 기록한다.
5. v7.1 §47 반복 횟수 기준에 따라 수정-재검증을 반복한다.
6. 종료 시 결과 요약을 사용자에게 보고한다.

## 필수 게이트 (현 Phase 기준 자동 적용)

| 기능 분류 | 필수 게이트 |
|---|---|
| 가벼운 UI | 0, 1, 2, 5, 6, 9 |
| 일반 기능 | 0, 1, 2, 3, 5, 6, 8, 9 |
| DB/API 포함 | 0~9 |
| 보안/개인정보 포함 | 0~11 |

Codex 위임이 없으므로 게이트 12·13은 v1에서 비활성.

## 출력

- 통과 / 실패 / 미실행 / 수동확인필요 카테고리로 요약
- 실패 항목은 파일·줄·원인 추정 함께 표시
- `docs/08_VALIDATION_LOG.md`에 자동 누적
