# 회귀 하네스

이전 Phase에서 통과했던 기능이 새 변경으로 깨지지 않았는지 확인한다.

## 1. 회귀 보호 대상

- 인증/세션 흐름 (Phase 2 산출물)
- 미니홈피 생성·기본 비공개 (Phase 3)
- URL/앨범/메모 CRUD (Phase 4~6)
- 꾸미기·레이아웃 저장 및 미리보기 (Phase 7)
- 공개/비공개 서버 검증 (Phase 9)
- 사용자 데이터 분리 (Phase 2~9 전반)

## 2. 실행 시점

- Phase 7부터 Phase 종료 시마다.
- 배포 전(`docs/15_RELEASE_CHECKLIST.md`)에 1회 추가.

## 3. 체크리스트

- [ ] 이전 Phase 테스트가 모두 통과 상태 유지인가
- [ ] 응답 포맷이 변경되지 않았는가(`success`, `data`, `error_code`, `message`, `details` 키 그대로)
- [ ] 기존 화면/메뉴명이 변경되지 않았는가
- [ ] `/u/[slug]` URL 스킴이 유지되는가
- [ ] `is_public` 기본값이 여전히 `false`인가
- [ ] 모든 자원 조회가 `deleted_at IS NULL`을 유지하는가
- [ ] 새 기능 추가 후 기존 사용자 흐름(PRD §4 1사이클)이 끊김 없이 작동하는가
