# UI 흐름 하네스

`docs/04_UI_FLOW.md`의 9개 화면 흐름을 사용자 관점에서 검증한다.

## 1. 도구

- 수동 시나리오 + Playwright(권장, Phase 7 이후 자동화).
- 브라우저: Chrome 최신, Safari/iOS Safari 1종.

## 2. 핵심 흐름 (PRD §4 성공 기준 1사이클)

- [ ] `/signup` → 가입 → `/login` → 로그인 → `/(admin)` 진입
- [ ] `/(admin)/settings`에서 slug 확정 (또는 자동 생성된 기본 slug 확인)
- [ ] `/(admin)/urls`: URL 3건 추가/수정/삭제
- [ ] `/(admin)/albums`: 카테고리 추가/이름 수정/삭제, 사진 3장 업로드/삭제
- [ ] `/(admin)/memos`: 메모 3건 작성/수정/삭제
- [ ] `/(admin)/decorate`: 배경색/이미지/포인트색/글자색/카드/폰트 변경 → **레이아웃 single/double 전환 + 슬롯별 위젯 배치 변경** → 미리보기 즉시 반영 확인 → 저장
- [ ] `/(admin)/settings`: 공개로 토글
- [ ] 시크릿 창에서 `/u/[slug]` 접속 → 정상 노출, 꾸미기·레이아웃 일치
- [ ] 다시 비공개 → `/u/[slug]` 404

## 3. 꾸미기 미리보기 전용

- [ ] 좌측 값 변경 시 우측 미리보기가 저장 없이 즉시 반영되는가
- [ ] single↔double 전환 시 슬롯 행 개수가 4↔6으로 동기화되는가
- [ ] 같은 위젯 중복 할당 시 클라이언트가 경고 + 저장 비활성화하는가
- [ ] 모바일 viewport에서 우측 미리보기가 1단 폴백되는가

## 4. 접근성/반응형

- [ ] 모든 폼 요소에 label이 연결되어 있는가
- [ ] 키보드 탭 이동만으로 핵심 흐름을 완료할 수 있는가
- [ ] 모바일에서 `/u/[slug]`가 깨지지 않는가

## 5. 체크리스트

- [ ] 9개 화면이 모두 접근 가능한가
- [ ] 비로그인 사용자가 `/(admin)/**`에 접근 시 `/login`으로 리다이렉트되는가
- [ ] 공개와 비공개의 외부 응답이 동일 메시지인가
- [ ] 결과를 `docs/08_VALIDATION_LOG.md`에 기록했는가
