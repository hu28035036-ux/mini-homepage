# UI 흐름 / 화면 구성 문서

본 문서는 본 미니홈피 서비스의 **9개 화면**을 단일 소스로 정의한다. 다른 문서는 본 문서를 참조한다.

## 1. 화면 목록

| # | 경로 | 권한 | 역할 |
|---|---|---|---|
| 1 | `/login` | 공개 | 로그인 |
| 2 | `/signup` | 공개 | 회원가입 |
| 3 | `/(admin)` (예: `/admin` 또는 `/`) | 로그인 필요 | 관리자 홈 |
| 4 | `/(admin)/urls` | 로그인 필요 | URL 보관함 |
| 5 | `/(admin)/albums` | 로그인 필요 | 앨범집 |
| 6 | `/(admin)/memos` | 로그인 필요 | 메모장 |
| 7 | `/(admin)/decorate` | 로그인 필요 | 꾸미기 탭 (핵심) |
| 8 | `/(admin)/settings` | 로그인 필요 | 설정 탭 |
| 9 | `/u/[slug]` | 공개(서버 검증) | 공개 미니홈피 |

## 2. 화면별 구성

### 2-1. `/login`
- 요소: 이메일 입력, 비밀번호 입력, 로그인 버튼, 회원가입 이동 링크
- 호출 API: `POST /api/auth/login`
- 실패 UI: `AUTH_INVALID_CREDENTIAL`은 "이메일 또는 비밀번호가 올바르지 않습니다." (이메일 존재 여부를 분리해서 알리지 않음)

### 2-2. `/signup`
- 요소: 이메일, 비밀번호, 비밀번호 확인, 닉네임, 가입 버튼
- 검증: 클라이언트에서 형식만, 서버가 zod로 재검증
- 호출 API: `POST /api/auth/signup`
- 가입 후: 로그인 화면으로 이동(자동 로그인은 v1 비채택, 명시적 로그인 요구)

### 2-3. `/(admin)` 관리자 홈
- 헤더: 미니홈피 제목, 공개/비공개 배지, 공개 페이지로 가기 버튼(`/u/[slug]`)
- 카드:
  - 최근 저장한 URL 5개
  - 최근 올린 사진 6장
  - 최근 작성한 메모 3개
  - 꾸미기 바로가기
- 호출 API: `GET /api/homepage`, `GET /api/urls`, `GET /api/albums/photos`, `GET /api/memos`

### 2-4. `/(admin)/urls`
- 상단: URL 추가 폼(제목, 주소)
- 본문: URL 목록 표(제목, 주소, 저장날짜, 수정, 삭제)
- 행동: 추가/수정/삭제. 수정은 인라인 모달 또는 행 expand
- 호출 API: `GET/POST/PATCH/DELETE /api/urls(/[id])`

### 2-5. `/(admin)/albums`
- 좌측: 카테고리 목록 + 카테고리 추가 버튼
- 우측: 선택한 카테고리의 사진 그리드 + 사진 업로드 버튼 + 사진 삭제
- 카테고리 수정: 이름 변경 모달
- 호출 API: `GET/POST/PATCH/DELETE /api/albums/categories(/[id])`, `GET/POST/DELETE /api/albums/photos(/[id])`

### 2-6. `/(admin)/memos`
- 상단: 메모 작성 폼(제목, 내용)
- 본문: 메모 목록(제목, 내용 일부, 작성날짜) + 상세 보기 모달/페이지
- 행동: 작성/상세/수정/삭제
- 호출 API: `GET/POST/PATCH/DELETE /api/memos(/[id])`

### 2-7. `/(admin)/decorate` 꾸미기 탭 (핵심)

좌측 패널(편집기) / 우측 패널(미리보기) 2분할.

좌측 편집기 섹션 순서:
1. **배경** — 배경색(컬러 피커), 배경 이미지 업로드, 배경 이미지 사용 ON/OFF
2. **색상** — 포인트 색상, 글자 색상
3. **카드 스타일** — 4종 라디오: `basic / rounded / shadow / transparent`
4. **폰트** — 3종 라디오: `default / rounded / emotional` (실제 적용 가능한 웹폰트 기준)
5. **레이아웃 모드** — 2종 라디오: `single / double`
6. **슬롯 배치** — 슬롯 행마다 (슬롯 번호 / 위젯 드롭다운[profile, urls, albums, memos, empty] / 표시 ON/OFF 토글)
   - single 모드: 4슬롯
   - double 모드: 6슬롯
   - 같은 위젯(empty 제외)을 두 슬롯에 동시 할당하면 클라이언트가 즉시 경고 + 저장 비활성화. 서버도 `LAYOUT_WIDGET_DUPLICATED`로 거절.
7. **저장 버튼** — `PUT /api/decorate` 호출

우측 미리보기 패널:
- 더미 데이터로 위젯을 그리며, 좌측 편집 결과를 **즉시 반영** (로컬 state, 서버 미반영).
- 더미 데이터:
  - profile: 닉네임 "미리보기", 한 줄 소개 "나만의 공간을 꾸미는 중...", 회색 원 프로필
  - urls: 1건 "다시 보고 싶은 사이트 / https://example.com / 오늘 날짜"
  - albums: 카테고리 "기본 앨범", 사진 3장 placeholder
  - memos: 1건 "오늘의 메모 / 나만의 공간을 꾸미는 중..."
- 레이아웃 모드/슬롯 배치도 즉시 반영. 1단은 세로 스택, 2단은 좌우 컬럼.
- 모바일 viewport에서는 자동 1단 폴백을 우측 패널에서도 동일하게 적용.

### 2-8. `/(admin)/settings`
- 미니홈피 제목, 한 줄 소개, 프로필 이미지 업로드, slug 주소(편집), 공개/비공개 토글, 저장 버튼
- slug 변경 시 중복 확인(`HOMEPAGE_SLUG_DUPLICATE` 표시)
- 공개로 변경 시 안내 모달: "외부에서 `/u/[slug]`로 접근할 수 있게 됩니다. 계속하시겠어요?"
- 호출 API: `PATCH /api/homepage`, `POST /api/decorate/profile-image`

### 2-9. `/u/[slug]` 공개 미니홈피

- 서버에서 `/api/public/[slug]`(또는 서버 컴포넌트가 직접 service 호출)로 `is_public AND deleted_at IS NULL` 검증.
- 비공개/없음 시: **404 Next.js 페이지**. 사용자에게는 "이 미니홈피는 비공개 상태이거나 존재하지 않습니다." 안내. (존재 여부 분리해서 알리지 않음.)
- 공개 시:
  - 헤더: 프로필 이미지, 닉네임/미니홈피 제목, 한 줄 소개
  - 본문: 저장된 `layout_mode`/`layout_slots`에 따라 위젯 배치
    - `profile` 위젯: 위 헤더와 별개의 프로필 카드(중복 가능, 사용자 선택)
    - `urls` 위젯: 최근 URL 카드 목록
    - `albums` 위젯: 카테고리별 최근 사진 그리드
    - `memos` 위젯: 최근 메모 카드
    - `empty` 또는 `visible=false`: 렌더링하지 않음
  - 스타일: 저장된 배경색/배경 이미지/포인트색/글자색/카드 스타일/폰트 그대로 적용
  - 메뉴: 홈 외에 URL / 앨범 / 메모 탭(또는 단일 페이지 섹션 내비게이션). v1은 단일 페이지 섹션 스크롤로 단순화.

## 3. 사용자 흐름 (핵심 시나리오)

1. 신규 가입 → 로그인 → `/(admin)`에서 미니홈피 자동 생성 또는 생성 안내 → `/(admin)/settings`에서 slug 확정.
2. URL/앨범/메모를 한두 건씩 등록.
3. `/(admin)/decorate`에서 꾸미기 + 레이아웃·슬롯 조정 → 저장.
4. `/(admin)/settings`에서 공개로 토글.
5. 시크릿 창에서 `/u/[slug]` 접속 → 정상 노출 확인.
6. 다시 비공개 → 외부 접속 시 404 확인.

## 4. UI 변경 금지사항

- 헤더의 메뉴명(홈 / URL / 앨범 / 메모) 임의 변경 금지.
- `/u/[slug]` URL 스킴 변경 금지.
- 미니홈피 기본 비공개 동작(생성 직후 `is_public=false`) 변경 금지.
- 비공개/없음을 서로 다른 메시지로 분리해서 노출하지 않음(보안).
- 꾸미기 탭의 미리보기와 실제 공개 페이지 렌더링 결과가 시각적으로 일치해야 함.

## 5. 반응형/접근성 (v1 최소 기준)

- 모바일(< md): `layout_mode='double'`이어도 우측 패널·공개 페이지 모두 1단으로 폴백.
- 모든 폼 요소에 label 연결.
- 색상 대비: 배경 이미지가 ON일 때 카드 배경 불투명도 자동 적용(예: `bg-white/80`).
- 키보드 탭 이동 가능.
